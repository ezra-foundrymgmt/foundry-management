# AI governance

CreatorOS remains valuable with every LLM offline. Deterministic rules gather metrics, detect anomalies, identify a root-cause branch, and construct evidence-backed actions before optional enrichment.

Risk levels range from 0 (read) through 5 (prohibited). AI may read tenant-scoped operational data and create low-risk internal tasks when authorized. Provisioning can only occur through approved deterministic workflows. External communication requires human approval. Sensitive payout, banking, KYC, tax, recovery, legal-signature, or credential changes are never exposed as AI tools.

The tool registry requires a permission, risk level, approval flag, and version. Every invocation is tenant scoped and auditable. Prompts and logs receive only the minimum necessary structured data and exclude secrets and prohibited personal data.
