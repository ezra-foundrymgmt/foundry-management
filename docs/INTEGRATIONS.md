# Integrations

## Implemented

- Typed provider contracts for Slack, Notion, file storage, creator revenue, and intelligence.
- Provider-independent workflow calls and persisted external resource identifiers.
- Connection registry and health states.
- OnlyFans-compatible generic revenue seam without scraping or browser automation.

## Mock

- Slack channel provisioning, topics, invitations, messages, and archive contract.
- Notion Creator Hub and internal resource provisioning contract.
- Approved creator file-structure provisioning.
- Deterministic creator revenue data.
- Rules intelligence provider.

Mock resources are labeled `MOCK` in the UI and are not live external resources.

## Planned

- Approved Slack, Notion, and Google OAuth applications.
- Official social-platform connectors.
- Approved revenue API, MCP, warehouse, or manual-export adapters.
- Optional Claude/OpenAI enrichment.
- PostHog and custom MCP tools.

No unsupported OnlyFans automation, scraping, password sharing, payout changes, or policy circumvention is implemented.
